# LEVEL QUEST

毎日のトレーニングを「デイリークエスト」にして、達成するとレベルが上がっていく肉体管理アプリ（PWA）です。
ゲームのシステム画面のような見た目で、スマホでも PC でも使えます。
現実で鍛えるほど主人公が強くなる **放置型ダンジョンRPG** も入っています。

**スマホのホーム画面から起動する手順は [docs/smartphone-setup.md](docs/smartphone-setup.md) を見てください。**

## 遊び方・機能

| 画面 | できること |
| --- | --- |
| クエスト | 今日のデイリークエスト（腕立て伏せ・腹筋・スクワット・ランニング）。+1/+5/+10 ボタンや数値の直接入力で記録。全部達成でクリア → 経験値。0時までの残り時間を表示 |
| ダンジョン | 主人公と仲間が自動で戦いながら地下へ進む放置型RPG（ドット絵）。10階ごとに1章の物語とボス。倒れると10階単位のチェックポイントに戻る。ゴールドで訓練（攻撃・HP・防御）、装備は自動で付け替え／売却。離れていた間の放置報酬あり |
| キャラクター | 最初の主人公はオリジナルの「灰の放浪者」（64×64 の描きおろし、待機の呼吸と剣を振り上げる動きあり）。または主人公のドット絵を部品から作る（髪型・髪色・肌・目・服・武器・眼鏡・ひげ）。**写真から作る**こともできる（AI が近い部品を選ぶ。写真は保存しない） |
| ステータス | レベル・ランク（E〜S）・経験値、能力値（STR/VIT/AGI/SEN/INT）へのポイント振り分け、次のレベルでの目標、称号の獲得と装備 |
| からだ | 体重・体脂肪率・ウエスト・メモの記録、BMI、推移グラフ（30日／90日／全期間） |
| 記録 | クリア回数・連続日数・達成率、15週間のカレンダー、種目ごとの累計 |
| 設定 | 種目の追加・編集（Lv.1の目標／1Lvごとの増加量／上限）、プリセット、休息日の曜日、バックアップと復元 |

### ルール

- 最初は各 10 回・1 km から。レベルが 1 上がるごとに +2 回・+0.2 km、上限は 100 回・10 km（Lv.46 で到達）
- その日の目標は朝（最初に開いたとき）に決まり、途中でレベルが上がっても変わらない
- クリア報酬は経験値 100 ＋ 連続クリアボーナス（1日ごとに +10、最大 +100）
- 次のレベルまでの必要経験値は `100 + (レベル - 1) × 25`。レベルアップごとに能力値ポイント +3
- 未達成のまま日付が変わると、次のクエストにペナルティ項目（バーピー）が追加される。連続記録も途切れる
- 休息日に設定した曜日はクエストがなく、連続記録も途切れない

### ダンジョンの物語（オリジナル）

下の階へ進むほど敵が強くなります。10階ごとに1章で、章の最後の階（10・20・30…階）にボスがいます。
7章を越えると、強さを増して2周目に入ります。

| 章 | 階 | 舞台 | ボス | 仲間 |
| --- | --- | --- | --- | --- |
| 1 | B1〜10F | E級「灰色の地下道」 | 地下道の番犬 | 主人公のみ |
| 2 | B11〜20F | D級「骨の回廊」 | 骨の騎士団長 | 癒し手ミオ（回復） |
| 3 | B21〜30F | C級「獣たちの森層」 | 森の王獣 | 盾の戦士ゴウ（被ダメージ−20%） |
| 4 | B31〜40F | B級「灼熱の坑道」 | 炎獄竜 | 魔導士セイラ（防御無視の魔法） |
| 5 | B41〜50F | A級「氷結の深層」 | 氷晶の巨像 | 銀狼ハク（素早い連続攻撃） |
| 6 | B51〜60F | S級「魔界の門」 | 門の魔王 | |
| 7 | B61〜70F | ?級「星の深淵」 | 深淵の主 | |

仲間の強さは主人公の攻撃力に比例するので、現実で鍛えるほど仲間も強くなります。

### 肉体管理とダンジョンのつながり

主人公のレベルは **現実のデイリークエストでしか上がりません**。ゲーム内で手に入るのはゴールドと装備だけです。

| 現実でやること | ダンジョンの主人公 |
| --- | --- |
| クエストを達成してレベルアップ | 攻撃 +2・HP +10・防御 +0.5（1レベルごと） |
| 能力値を振る（STR/VIT/AGI/SEN/INT） | 攻撃／HP・防御／攻撃速度・回避／会心率／スキル威力 |
| 腕立て伏せの累計 | 100回ごとに攻撃 +1%（ずっと続く） |
| スクワットの累計 | 100回ごとに HP +1% |
| 腹筋の累計 | 100回ごとに防御 +1% |
| ランニングの累計 | 5kmごとに攻撃速度 +1% |
| 今日のクエストを達成 | 「鍛錬の加護」：その日は攻撃・HP +15%、ゴールド +30% |
| ペナルティを消化していない | 「疲労」：攻撃 −10% |

## 仕組み

- Next.js（App Router）+ TypeScript + Tailwind CSS。サーバーは不要で、すべてブラウザで動きます
- 見た目はダークファンタジーのドット基調（ドット文字 DotGothic16、段々の枠、区切りのあるゲージ、SVG のドット絵）
- ドット絵は Scale2x で2倍の細かさにし、ハイライトと影を自動で付けて表示（`lib/pixel.ts`）
- ダンジョンの背景は階ごとに描く（章ごとの舞台＋階番号で飾りの配置が変わる。10階ごとのボス階は祭壇と旗）（`lib/scenes.ts`）
- 「写真から作る」だけはサーバー側の API（`/api/avatar`）で Claude を呼ぶ。使うときは環境変数 `ANTHROPIC_API_KEY`（と、おすすめで `APP_PASSCODE`）を設定する
- データは端末のブラウザ（localStorage）に保存。設定画面から JSON でバックアップ・復元できます

```
src/
  app/            page.tsx（クエスト） dungeon/ status/ body/ log/ settings/
  components/     Shell（ナビゲーション・日付の切り替わり確認） SystemNotices（クリアなどのお知らせ） ui
  lib/
    game.ts       ルール（目標の計算・経験値・ペナルティ・称号・連続日数）
    dungeon.ts    ダンジョンのルール（主人公の強さの計算・敵・装備・放置報酬）
    story.ts      物語（章・敵・ボス・仲間）
    sprites.ts    ドット絵のデータ（1文字 = 1ドット）
    avatar.ts     主人公の見た目の部品と組み立て
    pixel.ts      ドット絵を細かくする処理
    heroSprite.ts 灰の放浪者の 64×64 ドット絵（scripts/draw-hero.mjs で自動生成。手で編集しない）
    scenes.ts     階ごとの背景
    store.ts      保存と操作
    date.ts       日付の扱い
```

### 主人公「灰の放浪者」の絵を直すとき

`scripts/draw-hero.mjs` の図形（多角形・楕円・線）を直して `node scripts/draw-hero.mjs` を実行すると、
輪郭と陰影が自動で付いた 64×64 の絵（待機2コマ・攻撃1コマ）が `src/lib/heroSprite.ts` に書き出されます。

## 起動方法

```bash
cd quest-app
npm install
npm run dev     # http://localhost:3000
```

本番: `npm run build && npm start`。Vercel にデプロイする場合は Root Directory を `quest-app` にしてください。
