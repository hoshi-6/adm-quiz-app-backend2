# スマホでアプリとして使う手順

LEVEL QUEST をインターネット上に公開し、スマホのホーム画面から普通のアプリのように起動できるようにします。
費用はかかりません（Vercel の無料プランを使います）。データベースは使いません。「写真から主人公を作る」機能を使うときだけ Claude の API キーが必要です（使わなければ不要）。

> スマホの「ホーム画面に追加」は **https で公開された URL** でしか使えません。
> そのため、まず Vercel で公開し、その URL をスマホで開きます。

## STEP 1. Vercel で公開する（PC での作業がおすすめ・約5分）

すでに「ごはんナビ」を Vercel で公開している場合も、**同じリポジトリからもう1つプロジェクトを作ります**。

1. https://vercel.com にログインします（未登録なら「Continue with GitHub」で登録し、**Hobby（無料）** を選ぶ）。
2. ダッシュボードで「Add New…」→「Project」を押します。
3. 「Import Git Repository」の一覧から **`adm-quiz-app-backend2`** の「Import」を押します。
4. 設定画面で次のようにします。
   - **Project Name**: `level-quest` など（これが URL の一部になります）
   - **Root Directory**: 「Edit」を押して **`quest-app`** を選ぶ ← **ここが一番大事です**
   - Framework Preset: **Next.js**（自動で選ばれます）
   - 環境変数（Environment Variables）は基本的に**不要**です。
     「写真から主人公を作る」機能を使う場合だけ、次の2つを追加します（ごはんナビで使っている API キーと同じものでかまいません）。

     | Key | Value |
     | --- | --- |
     | `ANTHROPIC_API_KEY` | Claude の API キー（`sk-ant-…`） |
     | `APP_PASSCODE` | 合言葉（他人にあなたの API キーで AI を使われないようにするため） |
5. 「Deploy」を押します。1〜2分で完了します。
6. 表示された URL（例: `https://level-quest.vercel.app`）を控えます。

> 公開されるのは `main` ブランチの内容です。作業ブランチのままの場合は、先にプルリクエストを main にマージするか、
> Vercel の「Settings」→「Git」→「Production Branch」を作業ブランチに変えてください。

## STEP 2. スマホのホーム画面に追加する

### iPhone

1. **Safari** で STEP 1 の URL を開きます（Chrome ではホーム画面に追加できないことがあります）。
2. 画面下の **共有ボタン**（□ に ↑）を押します。
3. 下にスクロールして **「ホーム画面に追加」** を押します。
4. 名前が「LEVEL QUEST」になっていることを確認して「追加」を押します。
5. ホーム画面の青いアイコンから起動します。ブラウザの枠がない全画面で開きます。

### Android

1. **Chrome** で STEP 1 の URL を開きます。
2. 右上の **︙** → **「ホーム画面に追加」**（または「アプリをインストール」）を押します。
3. 「インストール」を押すと、ホーム画面とアプリ一覧にアイコンが追加されます。

## 知っておくこと

- **記録はスマホの中に保存されます。** PC とスマホでデータは共有されません。
  機種変更の前などは「設定」→「バックアップを保存」でファイルに書き出し、新しい端末で「バックアップから復元」してください。
- **iPhone では、Safari で開いたときとホーム画面から開いたときで、データが別々になります。** 使い始めたらホーム画面のアイコンから使ってください。
- 一度開けば、電波がない場所でも起動できます。
- アプリを更新（GitHub に新しい内容が入る）すると、Vercel が自動で公開し直します。スマホ側は次に開いたときに新しくなります。
