# ごはんナビ

家にある食材・調味料、今日食べたもの、不足している栄養素を管理し、
それらをもとに AI（Claude）が夕食などの献立を提案する、スマートフォン・PC 兼用の Web アプリ（PWA）です。

**スマホで使い始める手順は [docs/smartphone-setup.md](docs/smartphone-setup.md) を見てください。**

## 主な機能

| 画面 | できること |
| --- | --- |
| ホーム | 今日の摂取量と目標の比較、不足・超過している栄養素、期限が近い食材 |
| 食事記録 | 文章・料理の写真・ほかのアプリのスクリーンショットから AI が栄養素を調べて記録（市販品は公式の表示を Web 検索）。「在庫から」では在庫の商品を選び、登録済みの栄養成分で記録して在庫も減らす。手入力も可 |
| AI献立 | 在庫・今日の不足栄養素・好み／アレルギーをもとに 3 案（和食・洋食・中華/エスニック）を同時に作り、できたものから表示。「これを食べた」で記録し、使った食材を在庫から減らせる |
| 推移 | 栄養素ごとの日別グラフ（7日・2週間・30日）と、期間の平均・達成率 |
| 在庫 | 商品名の文章や写真（パッケージ・冷蔵庫・レシート）から、AI が実在の商品・1つあたりの内容量・栄養成分を調べて登録。「使う」で「1袋」「10g」などの量を選んで在庫を減らし、そのまま食事として記録できる。よく使う食材の候補表示、手での追加、賞味期限の管理 |
| 設定 | 性別・年齢・活動量から目標値を自動計算（日本人の食事摂取基準 2025 年版ベース）、個別編集、同期状態、バックアップ |

扱う栄養素（22 項目）:
- 主要: エネルギー、たんぱく質、脂質、飽和脂肪酸（上限）、炭水化物、食物繊維、食塩相当量（上限）
- ミネラル: カリウム、カルシウム、マグネシウム、鉄、亜鉛
- ビタミン: A、D、E、K、B1、B2、B6、B12、葉酸、C

目標値は厚生労働省「日本人の食事摂取基準（2025年版）」の成人の値（年齢区分・性別・身体活動レベル別）です。
食事の栄養推定では、市販品や外食チェーンのメニューは AI が Web 検索で公式の栄養成分表示を探して使います（出典リンク付き）。

## 仕組み

- **Next.js（App Router）+ TypeScript + Tailwind CSS**
- **データはクラウド（PostgreSQL）で同期**。スマホと PC で同じ在庫・食事記録・設定を使えます。
  各端末にも保存しているのでオフラインでも使え、つながったときに自動で同期します
  （同じ記録を両方で編集した場合は、後から編集した方が残ります）。
  データベースを設定しなければ、これまでどおり端末の中だけに保存します。
- クラウドのデータは **パスコード（`APP_PASSCODE`）** で保護しています。初めて開いた端末で一度入力します。
- **AI は Claude API** をサーバー側の API ルート（`/api/estimate`, `/api/suggest`）から呼び出します。
  API キーはブラウザに渡りません。構造化出力で JSON を受け取り、画面に表示しています。
- **PWA 対応**: スマホでは「ホーム画面に追加」でアプリのように使えます。

```
src/
  app/
    page.tsx            ホーム
    meals/ pantry/ suggest/ settings/   各画面
    api/estimate/       食事内容 → 栄養素推定
    api/suggest/        献立提案
    api/sync/           端末とクラウドの同期
    api/pantry-scan/    写真 → 在庫の候補
    api/products/       市販品の検索（Open Food Facts）
    trends/             栄養の推移グラフ
    manifest.ts         PWA マニフェスト
  lib/
    nutrients.ts        栄養素の定義・目標値計算・不足判定
    db.ts               端末内の保存（IndexedDB）と書き込み関数
    sync.ts             クラウドとの同期（端末側）
    server/store.ts     クラウドの保存（PostgreSQL。テーブルは初回に自動作成）
    ai/claude.ts        Claude API 呼び出し
    ai/schemas.ts       AI 入出力のスキーマ
```

## 起動方法

```bash
npm install
cp .env.example .env.local   # ANTHROPIC_API_KEY、APP_PASSCODE を記入（DATABASE_URL は任意）
npm run dev                  # http://localhost:3000
```

## 公開（デプロイ）

Vercel + Neon（PostgreSQL）での公開手順は [docs/smartphone-setup.md](docs/smartphone-setup.md) にまとめています。

| 環境変数 | 必須 | 内容 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | ✓ | Claude API キー |
| `APP_PASSCODE` | ✓ | アクセス用パスコード（クラウド同期を使うときは必須） |
| `DATABASE_URL` | 同期するなら ✓ | PostgreSQL の接続文字列（Vercel で Neon を接続すると自動設定。`POSTGRES_URL` でも可） |
| `CLAUDE_MODEL` | | 使うモデル（省略時 `claude-opus-5`） |
| `CLAUDE_LOOKUP_MODEL` | | 商品・食事の栄養を Web で調べるときだけ使うモデル（例: `claude-sonnet-5`。速く・安くなるが精度は下がることがある） |
| `CLAUDE_FAST_MODE` | | `1` にすると AI の出力が最大 2.5 倍速くなる高速モード（料金は約 2 倍。Opus 系のみ） |

## 注意

栄養素の値は AI による推定値で、目標値は一般的な成人向けの目安です。
妊娠・授乳中や持病・食事制限がある場合は、医師・管理栄養士の指示を優先してください。
