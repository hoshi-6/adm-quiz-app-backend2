# スマホで使い始める手順

ごはんナビをインターネット上に公開し、スマホ（と PC）から同じデータで使えるようにする手順です。
ここに出てくるサービスはどれも無料から始められます。AI の利用料だけは、使った分がかかります。

| 使うもの | 役割 | 費用 |
| --- | --- | --- |
| GitHub | アプリのプログラムの置き場所（すでにある） | 無料 |
| Anthropic（Claude API） | 栄養の推定・献立提案を行う AI | 従量課金（前払い） |
| Vercel | アプリを公開するサーバー | 無料（Hobby プラン） |
| Neon | スマホと PC で共有するデータベース | 無料枠あり |

所要時間は 20〜30 分ほどです。STEP 1〜3 は画面の広い PC で行うのがおすすめです（スマホのブラウザでもできます）。

---

## STEP 1. Claude の API キーを作る

1. https://console.anthropic.com を開き、アカウントを作成してログインします。
2. 「Billing（請求）」の画面でクレジットカードを登録し、クレジットを購入します（最低 5 ドル程度から）。
   - 前払い制なので、購入した額以上は請求されません。
   - 利用料の目安（`claude-opus-5` の場合）: 献立提案 1 回あたり十数円、食事の栄養推定 1 回あたり数円程度。
3. 「API Keys」の画面で「Create Key」を押し、名前（例: `gohan-navi`）を付けて作成します。
4. 表示された `sk-ant-` で始まる文字列をコピーして、メモ帳などに控えておきます。
   **この画面を閉じると二度と表示されないので注意してください。** 他人には教えないでください。

## STEP 2. パスコードを決める

アプリのデータを守るための合言葉です。スマホや PC で初めてアプリを開いたときに、一度だけ入力します。

- 他人に推測されにくい、長めの文字列にしてください（例: `natto-Tamago-2026-kome`）。
- STEP 1 のキーと一緒に控えておきます。

## STEP 3. Vercel でアプリを公開する

1. https://vercel.com を開き、「Sign Up」→「Continue with GitHub」で GitHub アカウントを使って登録します。
   - プランを聞かれたら **Hobby（無料）** を選びます。
2. ダッシュボードで「Add New…」→「Project」を押します。
3. 「Import Git Repository」の一覧から **`adm-quiz-app-backend2`** の「Import」を押します。
   - 一覧に出てこない場合は、「Adjust GitHub App Permissions」から、Vercel がこのリポジトリを読めるよう許可します。
4. 設定画面が開きます。
   - 「Framework Preset」が **Next.js** になっていることを確認します（自動で選ばれます）。
   - 「Environment Variables」を開き、次の 2 つを追加します。

     | Key（名前） | Value（値） |
     | --- | --- |
     | `ANTHROPIC_API_KEY` | STEP 1 でコピーした `sk-ant-…` |
     | `APP_PASSCODE` | STEP 2 で決めたパスコード |

5. 「Deploy」を押します。1〜2 分で完了し、お祝いの画面が出ます。

## STEP 4. データベース（Neon）をつなぐ

これで、スマホと PC のデータが共有されるようになります。

1. Vercel で、STEP 3 で作ったプロジェクトを開きます。
2. 上部の **「Storage」** タブを開き、「Create Database」を押します。
3. 一覧から **Neon**（Serverless Postgres）を選び、「Continue」を押します。
   - 地域（Region）は、日本から近いところ（例: Tokyo、Singapore）を選びます。
   - プランは **Free** を選びます。
4. 作成後、「Connect Project」でこのプロジェクトにつなぎます。
   - 環境変数 `DATABASE_URL` が自動で追加されます（自分で入力する必要はありません）。
5. **環境変数を反映させるため、もう一度公開し直します。**
   「Deployments」タブを開き、いちばん上の行の「⋯」→「Redeploy」を押します。

   データを保存する表は、アプリが最初に同期するときに自動で作られます。SQL を実行する必要はありません。

6. 「Domains」の欄に表示されている URL（例: `https://adm-quiz-app-backend2.vercel.app`）を控えます。
   これがアプリの URL です。

## STEP 5. スマホで開いて、ホーム画面に追加する

### iPhone の場合

1. **Safari** で STEP 4 の URL を開きます（Chrome などではホーム画面に追加できない場合があります）。
2. 「ごはんナビへようこそ」の画面で、STEP 2 のパスコードを入力して「はじめる」を押します。
3. 画面下の **共有ボタン**（□ に ↑ のアイコン）を押します。
4. メニューを下にスクロールし、**「ホーム画面に追加」** を押します。
5. 名前が「ごはんナビ」になっていることを確認して、「追加」を押します。
6. ホーム画面の「栄」アイコンから起動します。普通のアプリのように全画面で開きます。

   ※ ホーム画面から開いたアプリは Safari とは別扱いのため、**もう一度パスコードの入力を求められることがあります**。
   同じパスコードを入れれば、データはそのまま使えます。

### Android の場合

1. **Chrome** で STEP 4 の URL を開きます。
2. パスコードを入力して「はじめる」を押します。
3. 右上の **「⋮」** メニューから **「アプリをインストール」** または **「ホーム画面に追加」** を選びます。
4. 「インストール」を押すと、アプリ一覧とホーム画面に「ごはんナビ」が追加されます。

## STEP 6. 最初の設定（スマホで）

1. 下のタブの **「設定」** を開きます。
   - 性別・年齢・活動量を選ぶと、1 日の目標量が自動で計算されます。
   - 「好み・アレルギー・苦手なもの」に、アレルギーや苦手な食材を書いておきます（AI が必ず考慮します）。
   - 右上の **「保存」** を押します。
   - 「データの同期」の欄が **「クラウド同期：有効」** になっていれば、STEP 4 までの設定は完了です。
2. **「在庫」** を開き、家にある食材を登録します。
   - 賞味期限を入れておくと、期限が近いものを AI が優先して使います。
   - 「調味料」タブの「基本の調味料をまとめて追加」を押すと、塩・醤油などを一度に登録できます。

## 毎日の使い方

1. **食べたら「食事記録」**：「ご飯、豚の生姜焼き、味噌汁」のように書いて「栄養素を推定する」→ 内容を確認して記録します。
2. **「ホーム」で確認**：今日足りていない栄養素と、期限が近い食材がわかります。
3. **夕食前に「AI献立」**：「献立を提案してもらう」を押すと、足りない栄養素を補えて、家にある食材で作れる献立が 3 案出ます。
   - 提案には数十秒かかります。**その間はアプリを閉じずに待ってください**（閉じると結果を受け取れないことがあります）。
   - 作って食べたら「これを食べた（記録する）」を押すと、食事記録に追加されます。
4. **買い物をしたら「在庫」を更新**：使い切ったら「−」ボタンや「削除」で減らします。

## PC でも使う

PC のブラウザで同じ URL を開き、同じパスコードを入力するだけです。スマホと同じデータが表示されます。

- 変更は数秒で相手の端末に届きます。相手の端末では、アプリを開き直したとき（または 1 分ごと）に反映されます。
- 画面右上の「● 同期済み」で状態を確認できます。電波がないときは「オフライン」と表示されますが、
  そのまま記録でき、つながったときに自動で送られます。

## うまくいかないとき

| 症状 | 対処 |
| --- | --- |
| 「パスコードが違います」と出る | Vercel の「Settings → Environment Variables」で `APP_PASSCODE` の値を確認します。値を変えた場合は Redeploy が必要です |
| 設定画面に「クラウドが未設定のため…」と出る | STEP 4 の Neon の接続と、その後の Redeploy ができているか確認します |
| 「APP_PASSCODE が設定されていません」と出る | STEP 3 の環境変数 `APP_PASSCODE` を追加し、Redeploy します |
| AI で「ANTHROPIC_API_KEY が…」と出る | STEP 1 のキーが正しく入っているか、Anthropic のクレジット残高があるかを確認します |
| AI の提案が途中でエラーになる | 少し待ってから再度試します。続く場合は Vercel の「Logs」にエラー内容が出ています |
| 同じ記録が消えた・戻った | 同じ記録を 2 台で同時に編集すると、後から編集した方が残ります |

## 費用を抑えたいとき

Vercel の環境変数に `CLAUDE_MODEL` = `claude-sonnet-5` を追加して Redeploy すると、
より安いモデル（利用料はおよそ 4 割）に切り替わります。提案の質は少し下がることがあります。
